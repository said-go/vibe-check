# ВАЙБЧЕК

Шуточный локальный анализатор вайба по фотографии. Камера и фото обрабатываются прямо в браузере — изображения никуда не отправляются.

## Возможности

- съёмка с фронтальной камеры;
- загрузка фото с устройства;
- локальный анализ цвета, контраста и яркости;
- четыре результата: «Нефор», «Гот», «Здравый пацан», «Стиляга»;
- адаптивный интерфейс и системный Share API.

## Запуск

Проект не требует сборки. Откройте `dist/index.html` или запустите локальный сервер:

```bash
npx serve dist
```

Для доступа к камере в браузере нужен HTTPS или `localhost`.

## Дисклеймер

Результат носит развлекательный характер и оценивает визуальный «вайб», а не внешность человека.
