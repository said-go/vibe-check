# ВАЙБЧЕК

Шуточный локальный анализатор вайба по фотографии. Камера и фото обрабатываются прямо в браузере — изображения никуда не отправляются.

План разработки и текущие задачи: [KANBAN.md](KANBAN.md) и [GitHub Issues](https://github.com/said-go/vibe-check/issues).

## Возможности

- съёмка с фронтальной камеры;
- загрузка фото с устройства;
- локальный анализ цвета, контраста и яркости;
- независимые категория стиля и уровень цельности образа;
- установка как PWA и запуск интерфейса без сети;
- адаптивный интерфейс и системный Share API.

## Запуск

Проект не требует сборки. Откройте `dist/index.html` или запустите локальный сервер:

```bash
npx serve dist
```

Для доступа к камере в браузере нужен HTTPS или `localhost`.

## Архитектура текущего этапа

`taxonomy.js` содержит конфигурируемую таксономию и правила расчёта категорий. Текущий локальный анализ — демонстрационный. Следующий вертикальный этап заменит извлечение признаков на Vision AI через защищённый backend API, сохранив независимый Scoring Engine.

Backend-каркас находится в [`backend/`](backend/): Go API, OpenAPI, строгая JSON Schema визуальных признаков и покрытый тестами Scoring Engine. Загрузка фотографий и вызов Vision AI пока намеренно не подключены.

## Дисклеймер

Результат носит развлекательный характер и оценивает визуальный «вайб», а не внешность человека.
