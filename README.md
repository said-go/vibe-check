# ВАЙБЧЕК

PWA для развлекательного анализа стиля одежды по фотографии. Пользователь делает снимок или выбирает JPEG/PNG, подтверждает отправку фото в Yandex AI Studio и получает категорию стиля, балл цельности образа и рекомендации. Результат описывает одежду и видимые детали образа, а не внешность или личность человека.

## Запуск целиком

Нужны Go 1.25, API-ключ сервисного аккаунта Yandex Cloud и ID каталога. Список переменных есть в `backend/.env.example`; храните секреты только в окружении сервера. Из корня репозитория:

```powershell
$env:YANDEX_API_KEY = '<секретный ключ>'
$env:YANDEX_FOLDER_ID = '<id каталога>'
cd backend
go run ./cmd/api
```

Откройте `http://localhost:8080`. Сервер раздаёт PWA и API на одном адресе: `POST /api/v1/analyses`. Без ключа интерфейс работает, но запрос анализа возвращает `503 ai_unavailable`.

Для контейнера есть [Dockerfile](Dockerfile). В production ключ и ID каталога обязательны; передавайте их как секреты хостинга. Модель по умолчанию `qwen3.6-35b-a3b`, её можно изменить переменной `YANDEX_MODEL`.

## Как получается результат

Браузер отправляет снимок только после явного согласия. Go сервер проверяет формат и размеры, удаляет метаданные повторным кодированием в JPEG и передаёт очищенную копию в Yandex AI Studio. AI извлекает только признаки одежды и качества кадра по строгому JSON контракту. Отдельный Scoring Engine рассчитывает категорию и балл по фиксированным правилам. При недостаточной уверенности приложение просит другое фото.

Наш сервер не сохраняет фото в файлы, базу данных или логи. Обработка у провайдера регулируется условиями Yandex Cloud. Интерфейс PWA доступен офлайн, новый AI-анализ требует сети.

Правила категорий не используют национальность, религию, пол, привлекательность или другие чувствительные характеристики. Культурный контекст Северного Кавказа учитывается в нейтральных описаниях одежды; перед релизом запланирована проверка формулировок с пользователями региона.

## Статус публикации

Текущий адрес Sites публикует статические файлы. Для работающего анализа в интернете потребуется разместить Go backend с HTTPS и секретами Yandex Cloud, затем подключить PWA к его API. До этого интерфейс сообщает о недоступности сервера анализа.

Подробности API и переменных окружения: [backend/README.md](backend/README.md).
