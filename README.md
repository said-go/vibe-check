# ВАЙБЧЕК

PWA для развлекательного анализа стиля одежды по фотографии. Пользователь делает снимок или выбирает фото, которое может открыть браузер, подтверждает отправку в Yandex AI Studio и получает категорию стиля, балл цельности образа и рекомендации. Перед отправкой снимок уменьшается и сжимается в JPEG. Обычный AI-результат описывает одежду и видимые детали образа, а не внешность или личность человека.

## Запуск целиком

Нужны Go 1.25, API-ключ сервисного аккаунта Yandex Cloud и ID каталога. Для локального запуска впишите их в `backend/.env` после `YANDEX_API_KEY=` и `YANDEX_FOLDER_ID=`, затем из корня репозитория выполните:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\run-local.ps1
```

`backend/.env` исключён из Git; скрипт загружает его только в окружение локального процесса и не выводит значения. Для развёрнутого контейнера ключ передаётся из Lockbox, а не из этого файла. Образец переменных — `backend/.env.example`.

Откройте `http://localhost:8080`. Сервер раздаёт PWA и API на одном адресе: `POST /api/v1/analyses`. Без ключа интерфейс работает, но запрос анализа возвращает `503 ai_unavailable`.

Для контейнера есть [Dockerfile](Dockerfile) и [план развёртывания в Yandex Cloud](docs/DEPLOY_YANDEX.md). В production ключ и ID каталога обязательны; передавайте ключ через Lockbox. Модель по умолчанию `qwen3.6-35b-a3b`, её можно изменить переменной `YANDEX_MODEL`.

## Как получается результат

Браузер отправляет снимок только после явного согласия. Go сервер проверяет формат и размеры, удаляет метаданные повторным кодированием в JPEG и передаёт очищенную копию в Yandex AI Studio. AI возвращает JSON с признаками одежды и качества кадра; сервер проверяет поля и допустимые значения ответа. Отдельный Scoring Engine рассчитывает категорию и балл по фиксированным правилам. Если модель не выделила признаков одежды, приложение просит другое фото.

Для двух заранее согласованных снимков браузер вычисляет SHA-256 исходного файла до сжатия и передаёт отпечаток вместе со сжатым фото серверу. Сервер сверяет отпечаток и визуальное сходство, затем возвращает заданный владельцем развлекательный результат без обращения к Yandex AI. В репозитории есть только отпечатки, компактные визуальные признаки и вручную заданные тексты и баллы; сами фото не добавлены. Карточка выглядит так же, как обычный результат; её баллы для этих двух файлов не рассчитаны AI. После обрезки, повторного сохранения или пересылки с изменением файла точное совпадение может пропасть, и сработает обычный AI-анализ.

Наш сервер не сохраняет фото в файлы, базу данных или логи. Обработка у провайдера регулируется условиями Yandex Cloud. Интерфейс PWA доступен офлайн, новый AI-анализ требует сети.

Полученный результат можно по желанию сохранить в локальную историю браузера (до 50 записей), удалить отдельно или очистить целиком. В историю попадают только балл и текстовые данные; фото туда не записывается. Из результата и истории можно скачать PNG-карточку без фото. Кнопка «Поделиться» передаёт эту карточку через системное меню, если браузер поддерживает отправку файлов; иначе передаёт или копирует текст результата.

Правила категорий не используют национальность, религию, пол, привлекательность или другие чувствительные характеристики. Культурный контекст Северного Кавказа учитывается в нейтральных описаниях одежды; перед релизом запланирована проверка формулировок с пользователями региона.

[План проверки категорий и формулировок](docs/SCORING_REVIEW.md) объясняет различие между стилем и баллом и перечисляет сценарии для регионального тестирования.

## Статус публикации

Текущий адрес Sites публикует статические файлы. Живой анализ через Yandex AI локально проверен; для работы в интернете ещё требуется разместить Go backend с HTTPS и секретом в Yandex Cloud. До этого опубликованный интерфейс проверяет `/api/readyz`, сообщает о недоступности сервера и не отправляет фото.

Подробности API и переменных окружения: [backend/README.md](backend/README.md).

Проверки выполняются в GitHub Actions: Go тесты с race detector, `go vet`, синтаксис JavaScript и сборка Docker образа без публикации. Интеграционный тест проходит путь от загрузки PNG до ответа API через имитацию Yandex AI; живой вызов Яндекса проверен локально, а сценарий на публичном HTTPS-адресе остаётся шагом перед релизом.

Локальная проверка перед релизом: `pwsh -NoProfile -File scripts/preflight.ps1`. Успешный повтор того же снимка с `Idempotency-Key` возвращает прежний результат без нового вызова AI в пределах одного процесса и десяти минут.
